# Paper Phase Router

Use this when the full paper pipeline is too broad for the current task.

- framing / contribution -> load the umbrella
- literature discovery -> `arxiv` or `research-briefing`
- experiment planning -> umbrella or `plan`
- multi-role implementation/review -> `subagent-driven-development`
- drafting/revision with existing results in hand -> umbrella, but stay in the relevant phase instead of rereading the whole pipeline mentally

The full skill remains useful because paper work loops across phases, but many requests only need one phase at a time.
