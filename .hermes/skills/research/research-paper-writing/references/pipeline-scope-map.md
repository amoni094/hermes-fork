# Research Paper Pipeline Scope Map

Use this to decide whether to load the full research-paper-writing umbrella.

Load the full umbrella when the task spans multiple stages:
- contribution framing
- literature review
- experiment planning/execution
- analysis
- drafting/revision/submission

Use narrower companions when possible:
- paper discovery / related work -> `arxiv` or `research-briefing`
- planning/project breakdown -> `plan`
- multi-role execution/review -> `subagent-driven-development`

The full umbrella is intentionally broad because paper work is iterative, not linear.
