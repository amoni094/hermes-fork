# Mixed cluster sync pattern

Use this when the last 24 hours contain multiple durable themes that should both survive the rewrite.

## Example clusters
- infrastructure recovery / service persistence
- blocked-source policy / fallback-label changes
- social-render helper improvements

## Rule
Do not collapse these into one vague maintenance bullet. Keep each current cluster as its own recent-session subsection, even if one cluster is newer.

## Daily note handling
- Keep the daily block thin.
- Link `[[Hermes Chat Live Sync]]`.
- Mention both durable clusters only if they are still current.
- If the day only changed by timestamp maintenance, do not expand the daily note.
