# Live Sync Note Template

Use this as a compact rewrite template for `Hermes Chat Live Sync.md`.

## Frontmatter

```yaml
---
title: Hermes Chat Live Sync
date: YYYY-MM-DD
tags:
  - ai
  - hermes
  - obsidian
  - sync
status: active
last_synced: YYYY-MM-DD HH:MM TZ
scope: curated durable Hermes changes and verified results from the last 24 hours
---
```

## Body shape

```md
# Hermes Chat Live Sync

_Last synced: YYYY-MM-DD HH:MM TZ._

## Scope
Short statement that this is a curated durable summary, not a transcript.

## Recent Sessions
### Theme or session cluster
- Durable change
- Verified result
- Stable caveat if still relevant

## Key Durable Themes
- Cross-session truths that remain useful now

## Follow-Ups
- Only stable next actions, not every idea mentioned in chat

## Privacy Notes
- Note that raw transcripts, logs, and secrets were omitted
```

## Daily note checklist

Under `## Hermes Chat Sync` include:
1. Last synced timestamp
2. Link to `[[Hermes Chat Live Sync]]`
3. 2–4 concise bullets for the most durable new items

## Curation reminders

- Prefer rewrite over append.
- Keep only high-signal state.
- Merge related sessions into a few coherent themes.
- Preserve caveats only when they still affect future work.
