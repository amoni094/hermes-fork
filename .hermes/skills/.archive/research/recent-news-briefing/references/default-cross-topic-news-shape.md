# Default cross-topic news update shape

Use this when a user has an established recurring news bundle and asks for a generic "news update" or for "all the topics" associated with a research skill.

Recommended section order:
1. Main update window (usually last 7 days)
2. Finance / economics / markets
3. Geopolitics
4. Australia
5. US
6. Iran / regional conflict
7. Ukraine
8. AI / AI development
9. Git / GitHub popularity
10. Gaming
11. Trending (last 24h)
12. Blind spots outside the normal bundle

Interpretation notes:
- Do not equate an empty skill watchlist with "no topics" if the user has durable default topics for recurring updates.
- Treat missing social-source access as a coverage caveat, not as a reason to skip the briefing.
- If Reddit/X cannot be verified directly, label the substitute clearly: news prominence, recency, GitHub trending, or other accessible public signals.
- Keep caveats short and up front, then return to the expected section order.
