# Memory Topology Audit — 2026-08-08

## Summary

Full topology verification of the Hermes memory stack. Three issues found and fixed.

## Findings

### FIXED — Hindsight daemon crash-looping all session (HIGH)

**Root cause:** `~/.hindsight/profiles/hermes.env` was missing the 4 embeddings env vars.
The Hermes plugin (`_build_embedded_profile_env`) does not forward `HINDSIGHT_API_EMBEDDINGS_*`
keys from `config.json` to `hermes.env`. Daemon launched, tried to load BAAI/bge-small-en-v1.5
(384d local model as default fallback), hit dimension mismatch against existing 1536d DB (5182 rows),
and crashed with:
```
RuntimeError: Cannot change embedding dimension from 1536 to 384:
memory_units table contains 5182 rows with embeddings.
```

**Fix:** Appended 4 keys directly to `~/.hindsight/profiles/hermes.env`:
- `HINDSIGHT_API_EMBEDDINGS_PROVIDER=openai`
- `HINDSIGHT_API_EMBEDDINGS_OPENAI_API_KEY=<key from config.json>`
- `HINDSIGHT_API_EMBEDDINGS_OPENAI_MODEL=text-embedding-3-small`
- `HINDSIGHT_API_EMBEDDINGS_OPENAI_DIMENSIONS=1536`

Then killed stale lock (`rm ~/.hindsight/profiles/hermes.lock`), daemon restarted clean.
Verified: `hindsight_retain` returned `Memory stored successfully.`

**Note:** The values were present in `~/.hermes/hindsight/config.json` all along, stored as
JSON keys with the full `HINDSIGHT_API_EMBEDDINGS_*` names. The plugin just never forwarded them.

### FIXED — state.db world-readable (MEDIUM)

`stat -c "%a" ~/.hermes/state.db` returned `644`. Session transcripts contain full conversation
content. Fixed: `chmod 600 ~/.hermes/state.db`.

### FIXED — stealth-browser-mcp broken path (LOW)

Config had `args: ['server.py']` with `workdir: /var/home/rainbow/.hermes/mcp/stealth-browser-mcp/src`.
Python subprocess resolves relative `args[0]` against the calling process's cwd (~), not `workdir`.
Error in mcp-stderr.log (repeated every few minutes):
```
/var/home/rainbow/.hermes/mcp/stealth-browser-mcp/.venv/bin/python:
can't open file '/var/home/rainbow/server.py': [Errno 2] No such file or directory
```

Fix: `hermes config set mcp_servers.stealth-browser-mcp.args '["/var/home/rainbow/.hermes/mcp/stealth-browser-mcp/src/server.py"]'`

## Recurrence Risk

The Hindsight daemon crash will recur if `hermes.env` is regenerated by the plugin (Pitfall 3
in hindsight-stack-operations skill). After any `hermes update`, verify:
```bash
grep -c "EMBEDDINGS" ~/.hindsight/profiles/hermes.env   # expect 4
```
If returns 0, re-run the Pitfall 4 fix script.
