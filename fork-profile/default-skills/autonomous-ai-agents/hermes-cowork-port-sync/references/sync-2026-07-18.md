## Key design decisions

**Single-file-per-directory structure** — one comprehensive SKILL.md per topic area rather
than many narrow files. This makes the repo usable for an AI agent reading it directly
without needing to follow many cross-references.

**Dual-frame pattern for every major section** — each spec section has both:
- "Hermes does X" frame
- "Cursor does Y" Cursor-equivalent frame
  Side-by-side in tables where possible.

**Target reader is Cursor's AI agent**, not a human. Every spec must be self-contained
enough for the AI to action it directly without additional context.
