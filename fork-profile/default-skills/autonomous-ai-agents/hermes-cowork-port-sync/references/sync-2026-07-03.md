## Lessons

- Schedule values in the port repo drifted from the source (60m vs actual 240m).
  Always re-read the live cron snapshot rather than trusting the port's existing numbers.
- Two cron jobs (session-auto-prune, obsidian-weekly-review) were added to hermes-config
  without any corresponding port update. Check job count on every sync.
- Non-portable jobs need explicit "not portable" stubs in the port docs — silence creates
  a false impression the job doesn't exist.
- The memory topology section appears in three files (CLAUDE.md port strategy table,
  CLAUDE.md Hermes description, connectors/README.md). All three must be updated together.
- Graphiti and MemPalace must appear in: (1) MCP server table, (2) non-portable services
  table, (3) memory section — three locations total.
- Remote "repository moved" message on push is informational; push still succeeds.
