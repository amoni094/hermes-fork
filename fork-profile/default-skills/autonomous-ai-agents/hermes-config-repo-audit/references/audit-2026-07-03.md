- deliver mode is the most error-prone field in operations-surface-register.md
- Integration dirs in ~/.hermes/integrations/ are not the same as active integrations;
  need config.yaml cross-check to determine active vs dormant
- Patch-prepend trap: patching the top of current-workflow.md left the old stale
  Runtime/Core sections below. Fix: explicitly patch/replace the old sections too,
  or use write_file to overwrite cleanly.
- validate_repo.py passed on first try when audit was well-scoped to git-only writes
