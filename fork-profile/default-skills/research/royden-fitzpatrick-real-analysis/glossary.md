# Glossary: Real Analysis (Royden-Fitzpatrick)

**Absolute continuity (function)** — f: [a,b]→ℝ is AC iff ∀ε>0 ∃δ>0: Σ|f(bₖ)-f(aₖ)|<ε whenever Σ(bₖ-aₖ)<δ for disjoint intervals (Ch06)

**Absolute continuity (measure)** — ν ≪ μ: μ(E)=0 ⟹ ν(E)=0 (Ch18)

**Almost everywhere (a.e.)** — property holds except on a set of measure zero (Ch02)

**Arzelà-Ascoli Theorem** — F⊆C(X), X compact, has compact closure iff F is pointwise bounded and equicontinuous (Ch10)

**Baire Category Theorem** — A complete metric space is not meagre; countable intersection of dense open sets is dense (Ch10)

**Banach contraction principle** — Contraction T on complete metric space has unique fixed point; iterates converge geometrically (Ch10)

**Banach space** — Complete normed linear space (Ch07, Ch13)

**Borel sets** — σ-algebra generated by open sets; smallest collection containing opens closed under complements and countable unions (Ch01)

**Borel-Cantelli Lemma** — Σm(Eₙ)<∞ ⟹ m(lim sup Eₙ)=0: a.e. point in at most finitely many Eₙ (Ch02)

**Bounded variation (BV)** — TV[f] = sup_P Σ|f(xₖ)-f(xₖ₋₁)| < ∞; f = increasing − increasing (Ch06)

**Carathéodory condition** — E measurable iff m*(A)=m*(A∩E)+m*(A∩Eᶜ) for all A (Ch02)

**Closed graph theorem** — Linear T between Banach spaces with closed graph is bounded (Ch13)

**Compact operator** — Maps bounded sets to precompact sets; limit of finite-rank operators in Hilbert space (Ch16)

**Conjugate exponents** — 1/p + 1/q = 1 for 1<p<∞; 1 and ∞ are conjugate to each other (Ch07)

**Convergence in measure** — m({|fₙ-f|>η})→0 for all η>0 (Ch05)

**Countably additive (σ-additive)** — μ(∪Eₙ)=Σμ(Eₙ) for disjoint measurable {Eₙ} (Ch02)

**Dominated Convergence Theorem (DCT)** — fₙ→f a.e., |fₙ|≤g, ∫g<∞ ⟹ ∫fₙ→∫f (Ch04)

**Dual space X*** — Bounded linear functionals on X; [Lp]*=Lq, [L2]*=L2 (Ch08, Ch14, Ch16)

**Dunford-Pettis Theorem** — Bounded F⊆L1 weakly sequentially compact iff F uniformly integrable (Ch19)

**Eberlein-Smulian Theorem** — Weak compactness = weak sequential compactness in Banach spaces (Ch15)

**Egorov's Theorem** — m(E)<∞, fₙ→f a.e. ⟹ ∀ε ∃F⊆E with m(E\F)<ε and fₙ→f uniformly on F (Ch03)

**Equicontinuous family** — {fₙ} equicontinuous at x₀ iff ∀ε ∃δ (uniform over n): d(x,x₀)<δ ⟹ |fₙ(x)-fₙ(x₀)|<ε (Ch10)

**Essential supremum (ess sup)** — ess sup f = inf{M: m({f>M})=0} = ‖f‖_∞ (Ch07)

**Fatou's Lemma** — {fₙ}≥0 ⟹ ∫lim inf fₙ ≤ lim inf ∫fₙ (Ch04)

**Fredholm operator** — T = I - K where K compact; index = dim(ker T) - dim(ker T*) = 0 for Riesz-Schauder class (Ch16)

**Fubini-Tonelli Theorem** — Product measure iterated integrals: ∫_{X×Y}f d(μ×ν) = ∫_X∫_Y f dν dμ; Tonelli for f≥0, Fubini for ∫|f|<∞ (Ch20)

**Hahn-Banach Theorem** — Bounded functional on subspace extends to whole space preserving norm (Ch14)

**Hahn-Jordan Decomposition** — Signed measure ν = ν⁺ - ν⁻; X = P∪N positive/negative sets (Ch17)

**Haar measure** — Unique translation-invariant Borel probability measure on compact topological group (Ch22)

**Hilbert space** — Complete inner product space; [H]*≅H via Riesz-Fréchet (Ch16)

**Hölder's Inequality** — ∫|fg|≤‖f‖_p·‖g‖_q for 1/p+1/q=1 (Ch07)

**Inner product** — ⟨f,g⟩=∫fg; Cauchy-Schwarz: |⟨f,g⟩|≤‖f‖·‖g‖ (Ch16)

**Kakutani's Theorem** — X reflexive iff closed unit ball is weakly compact (Ch15)

**Krein-Milman Theorem** — Compact convex set = closed convex hull of its extreme points (Ch14)

**Lebesgue decomposition** — ν = νₐc + νₛ with νₐc≪μ, νₛ⊥μ; unique (Ch18)

**Lebesgue measure** — Complete, translation-invariant Borel measure on ℝ with m([0,1])=1 (Ch02)

**Lebesgue outer measure** — m*(A)=inf{Σℓ(Iₖ): A⊆∪Iₖ, Iₖ open intervals} (Ch02)

**Lp space** — {f measurable: ∫|f|^p<∞}/~, normed by ‖f‖_p=(∫|f|^p)^{1/p}; complete Banach space (Ch07)

**Lusin's Theorem** — f measurable and finite a.e. iff ∀ε ∃closed F with m(E\F)<ε and f|_F continuous (Ch03)

**Measurable function** — f: E→ℝ̄ with {f>c}∈M for all c∈ℝ (Ch03)

**Measurable set** — Element of the σ-algebra M; satisfies Carathéodory condition for Lebesgue measure (Ch02)

**Minkowski's Inequality** — ‖f+g‖_p ≤ ‖f‖_p+‖g‖_p; makes Lp a normed space (Ch07)

**Monotone Convergence Theorem (MCT)** — 0≤fₙ↑f a.e. ⟹ ∫fₙ→∫f (Ch04)

**Nonmeasurable set** — Vitali construction: a subset of ℝ not in M (requires Axiom of Choice) (Ch02)

**Normed linear space** — Vector space with norm ‖·‖ satisfying positivity, homogeneity, triangle inequality (Ch07, Ch13)

**Open mapping theorem** — Surjective bounded linear operator between Banach spaces is open (Ch13)

**Orthogonal complement** — Y⊥={x∈H: ⟨x,y⟩=0 ∀y∈Y}; H=Y⊕Y⊥ for closed Y (Ch16)

**Outer measure** — Monotone, countably subadditive set function with μ*(∅)=0; defined on all subsets (Ch02, Ch17)

**Radon-Nikodym derivative** — dν/dμ: unique f≥0 with ν(E)=∫_E f dμ when ν≪μ (Ch18)

**Radon-Nikodym Theorem** — ν≪μ (σ-finite) ⟹ ∃ unique f: ν(E)=∫_E f dμ (Ch18)

**Reflexive Banach space** — X≅X** via natural embedding J; Lp reflexive for 1<p<∞ (Ch14)

**Riesz-Fischer Theorem** — Lp(E) is complete for 1≤p≤∞ (Ch07)

**Riesz-Fréchet Representation** — T∈H* ⟺ T(h)=⟨h,g⟩ for unique g∈H, ‖T‖=‖g‖ (Ch16)

**Riesz Representation Theorem (Lp)** — [Lp]*≅Lq via Tg(f)=∫fg, for 1≤p<∞ (Ch08, Ch19)

**σ-algebra** — Collection of sets closed under complement and countable union; contains ∅ (Ch01, Ch17)

**σ-finite measure** — X=∪Xₙ with μ(Xₙ)<∞ (Ch17)

**Signed measure** — Countably additive set function ν: M→ℝ̄; decomposes as ν=ν⁺-ν⁻ (Ch17)

**Simple function** — ψ=Σaᵢ·1_{Eᵢ}, finitely many values on measurable sets (Ch03)

**Stone-Weierstrass Theorem** — Subalgebra of C(X) separating points + containing constants is dense in C(X) (Ch12)

**Tychonoff's Theorem** — Arbitrary product of compact spaces is compact (with product topology) (Ch12)

**Uniform Boundedness Principle (Banach-Steinhaus)** — sup_n|Tₙ(x)|<∞ ∀x ⟹ sup_n‖Tₙ‖<∞ (Ch13)

**Uniform integrability (UI)** — ∀ε>0 ∃M>0: sup_n ∫_{|fₙ|>M}|fₙ|<ε (Ch04, Ch05, Ch19)

**Urysohn's Lemma** — X normal, A,B disjoint closed ⟹ ∃f: X→[0,1] continuous with f|_A=0, f|_B=1 (Ch12)

**Vitali Convergence Theorem** — {fₙ} UI+tight, fₙ→f a.e. ⟹ ∫fₙ→∫f; generalizes DCT (Ch04, Ch05)

**Vitali-Hahn-Saks Theorem** — νₙ≪μ, νₙ(E)→ν(E) ⟹ ν≪μ and absolute continuity is uniform (Ch18)

**Weak convergence** — fₙ⇀f in Lp iff ∫fₙg→∫fg for all g∈Lq (Ch08, Ch19)

**Weak sequential compactness** — Bounded sequence in reflexive Banach space has weakly convergent subsequence (Ch15, Ch19)

**Weak-* topology** — On X*: pointwise convergence on X. Ball in X* is weak-* compact by Alaoglu (Ch15)

**Young's Inequality** — ab ≤ a^p/p + b^q/q for a,b≥0, 1/p+1/q=1; equality iff a^p=b^q (Ch07)
