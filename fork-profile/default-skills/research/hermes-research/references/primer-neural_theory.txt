PRIMER: Theory of Neural Networks

===

1. FIELD OVERVIEW

Theory of Neural Networks studies why and how deep learning systems learn despite being massively overparameterized (more weights than training samples). Core objects: loss landscapes, kernel regimes, expressivity measures, generalization bounds. Why it matters: classical learning theory predicts overparameterized models should overfit catastrophically. They don't. Understanding this gap—via Neural Tangent Kernels (NTK), mean-field theory, and loss landscape geometry—reveals when depth buys expressivity, when width suffices, and when optimization succeeds. For Hermes, this explains model scaling trade-offs, why larger models generalize better on out-of-distribution tasks, and principled routing decisions under resource constraints.

===

2. KEY RESULTS

Universal Approximation Theorem (Cybenko, 1989): A single hidden layer with finite neurons can approximate any continuous function on compact domains to arbitrary precision, given enough width. Bound: width ~ 1/ε^d (exponential in dimension d). Implication: width, not depth, suffices theoretically; depth is about sample efficiency and optimization speed.

Neural Tangent Kernel Convergence (Jacot et al., 2018): In the infinite-width limit with small learning rate, a wide network's training dynamics are equivalent to kernel regression with a fixed kernel K(x,x') = E[∂f/∂θ(x) · ∂f/∂θ(x')]. Convergence rate: gradient descent achieves zero training loss in O(log(1/ε)) steps. Implication: very wide networks are linear learners; nonlinearity comes from finite width.

Double Descent Risk Curve (Belkin et al., 2019): Test error first decreases (classical U), rises near interpolation threshold (bias-variance trade-off), then decreases again as model capacity increases beyond samples. Peak occurs at sample-size-matching. Implication: interpolating overparameterized models generalize well; bias dominates variance in the overparameterized regime.

Lottery Ticket Hypothesis (Frankle & Carbin, 2019): A randomly initialized dense network contains subnetworks that, when trained in isolation at the original learning rate, match full-network accuracy. Sparse masks exist; finding them requires iterative pruning. Implication: many weights are irrelevant; the effective capacity is much lower than parameter count.

===

3. STANDARD PRACTITIONER TOOLS

Gradient descent analysis: verify loss landscape convexity locally via Hessian eigenvalue bounds; use learning rate ~ 1/(L-smoothness constant). NTK kernel computation: finite-width corrections via Edamame expansions or empirical kernel centering. Loss landscape visualization: PCA of weight trajectories, barrier penetration depth. Width scaling: empirical scaling laws (test loss ~ N^{-α}; α typically 0.5–2). Overparameterization regime detection: compute condition number of Gram matrix; if >> 1, kernel regime likely dominates. Pruning baselines: magnitude pruning, layer-adaptive sparsity (LAMP), iterative magnitude pruning (IMP).

4. HERMES APPLICATIONS

COMPONENT: Model Routing (Claude/GPT/Grok/Mistral choice per subtask)

(a) Mathematical structure: Model capacity and loss landscape geometry. Smaller models have narrower loss landscapes; larger models interpolate but need careful initialization. Task difficulty modulates the sample complexity / capacity trade-off: hard tasks need depth (nonlinearity), easy tasks benefit from width (robustness).

(b) Hermes current approach: Heuristic scoring per model based on token cost, latency, historical success rate on similar tasks. No explicit tie to capability structure.

(c) Principled approach: For each candidate model, estimate effective capacity via Rademacher complexity bound: Rgen ~ O(sqrt(d log(n) / n)) where d = VC dimension proxy (e.g., product of layer widths in log scale), n = task samples seen. Rank by capacity-to-cost ratio. For subtasks with few demonstrations (n << d), prefer narrower models (Claude-3.5-Haiku); for tasks with rich context, wider models (Claude-3-Opus) tolerate interpolation better. Use double-descent lens: if task is near interpolation threshold for a model, risk overfitting; jump to next-larger model or regularize (e.g., context pruning).

(d) Value assessment: Medium-high ROI, moderate effort. The VC dimension estimates will be crude, but relative ranking should be robust. Risk: LLM effective capacity is not well-characterized empirically per task; transfer across domains may fail. Honest alternative: A/B test model routing rules quarterly with small budget allocation (5-10% of tasks) to gather empirical loss curves. Theory guides priors, but data should drive final rules.

COMPONENT: Fine-tuning for Task Adaptation (Skills system)

(a) Mathematical structure: When a base model is fine-tuned on task-specific data, the loss landscape shifts. NTK theory predicts that fine-tuning modulates the kernel; mean-field theory shows that adaptation happens in a low-dimensional subspace orthogonal to pretraining trajectory. Lottery ticket principle suggests that task-relevant weights are a sparse subset of pretrained weights.

(b) Hermes current approach: Load procedural skill files, prepend to prompt context per task type. No weight updates; pure in-context learning via prompt design.

(c) Principled approach: Use the lottery ticket perspective to identify task-critical weights: (i) Forward-backward pass on skill examples to compute importance scores (gradient × weight magnitude or Fisher information). (ii) Fine-tune only top-k% of weights (e.g., 5–15% chosen by importance); freeze the rest. This is LoRA-adjacent but with principled sparsity. Bound generalization via: Rgen ~ sqrt(|active weights| * log(n) / n_skill_samples). Pre-compute this bound at fine-tune time; if bound exceeds risk threshold, acquire more skill examples or reduce active weight set.

(d) Value assessment: High effort, moderate-to-high ROI. Fine-tuning introduces new failure modes (catastrophic forgetting, overfitting on small skill sets). The theory helps quantify safety: compute bound before deployment. Major risk: LLMs violate NTK assumptions (highly nonlinear, finite width dominates). Lottery ticket hypothesis empirically holds for CNNs/transformers but transfer to LLM task adaptation is unproven. Recommend: spike on 3-4 core skill types with small fine-tune budgets (e.g., 500 tokens) before scaling.

COMPONENT: Model Consensus and Aggregation (hermes-swarm-consensus)

(a) Mathematical structure: Ensemble learning as kernel method. If models are diverse (low correlation), ensemble risk is sum of individual risks minus interaction term. Overparameterized models trained differently explore different loss landscape valleys; averaging predictions averages their implicit regularizers. Double descent applies at ensemble level: adding mediocre models can hurt until enough diversity is achieved.

(b) Hermes current approach: Aggregate verdicts via majority vote or weighted score, weights set by historical accuracy. No principled diversity measure.

(c) Principled approach: Model diversity quantifies via empirical kernel alignment (EKA) or neural collapse metrics. For each model pair (M_i, M_j), compute correlation ρ_ij of prediction errors on validation tasks. Target ρ_ij < 0.7 (anti-correlated better than correlated). Prove-by-construction diversity via: (i) Route different subtasks to different models deterministically (e.g., route reasoning tasks to Claude, code tasks to Grok). (ii) If consensus fails (disagreement > threshold), spawn a debate subagent with cold-adversary review (already in Hermes). (iii) Bound ensemble risk: R_ensemble <= (1/m) * sum R_i + correlation_penalty * avg ρ_ij. Optimize model assignment to minimize this bound.

(d) Value assessment: Moderate effort, high impact on robustness. The diversity metric is concrete and computable. Risk: Correlation structure may change over time (task distribution drift); requires periodic re-calibration. Also, theory assumes models are trained independently; Hermes models share pretraining, reducing effective diversity. Workaround: introduce explicit decorrelation loss at routing time. Recommend a sprint on measuring current ρ_ij across Hermes models; if already > 0.8, diversity is limited and consensus gains are low.
