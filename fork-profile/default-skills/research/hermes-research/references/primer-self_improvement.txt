PRIMER: Agent Self-Improvement and Meta-Learning

================================================================================
FIELD OVERVIEW
================================================================================

Agent Self-Improvement and Meta-Learning studies how autonomous systems can
iteratively enhance their own capabilities through experience, reflection, and
task distribution. The core objects of study are: (1) Reflexion loops—
structured introspection on failed trajectories to extract generalizable rules;
(2) skill acquisition from traces—distilling procedural knowledge into
reusable, composable modules; (3) prompt optimization—treating the policy
instruction as a learnable artifact; (4) self-play scaling laws—how multi-model
consensus and adversarial review compound convergence speed. Mathematically,
this is non-stationary learning under partial observability: the agent's policy
P(action | state, skills) co-evolves with skill quality S(skill_id) and the
instruction manifold I, all while the environment distribution E shifts as
the agent solves harder problems. Why this matters: in multi-agent and
multi-model systems, centralized fine-tuning is infeasible; instead,
distributed reflection and skill curation become the binding constraint on
throughput and quality.

================================================================================
KEY RESULTS
================================================================================

RESULT 1: Reflexion Memory Pass-Rate Improvement (Shinn et al., 2023).
Given a task sequence with initial pass@1 = p_0, a Reflexion loop that
stores (trajectory, failure reason, correction rule) in episodic memory
improves pass@1 to p_0 + delta_p, where delta_p ≈ 0.15--0.30 on reasoning
tasks. The gain decays as 1 / sqrt(episode_count) if the rule set does not
diversify (curse of repetition). Mechanism: hindsight abstraction converts
low-level execution traces into high-level invariants P(should_use_skill_k |
task_context).

RESULT 2: Self-Play Scaling for Multi-Model Consensus (team scaling laws).
When m models independently solve a task, then aggregate verdicts via voting,
the combined error rate E_ensemble ≤ min_i E_i * (1 - delta_agree), where
delta_agree is the disagreement entropy. For Claude + GPT + Grok (~3 models),
expect ~0.08-0.12 error reduction per additional model up to m=5; diminishing
return beyond. Proof relies on independence; correlation from shared training
data reduces gain by ~40%.

RESULT 3: Prompt Optimization Convergence (Prompt Gradient Descent).
Treating instruction text I as a differentiable object in semantic space
(e.g., via embedding distance), beam search over candidate edits converges
in O(log K * D) rounds, where K is vocabulary size and D is instruction
dimensionality. Empirically, 10-30 rounds suffice for 5-10% improvement.
Convergence is brittle: local optima abound, and gradient signal from pass@1
is sparse.

RESULT 4: Skill Acquisition from Traces (Inverse Reinforcement Learning on
Trajectories). A skill s_new extracted from n successful trajectories tau_i
generalizes to held-out tasks with error bounded by error_extraction +
error_generalization, where error_extraction ≈ 1/n (number of exemplars) and
error_generalization depends on task similarity (Wasserstein distance in
feature space). Compressed skills (< 5KB) often saturate; larger skills (>20KB)
incur cognitive load but tolerate more distribution shift.

================================================================================
STANDARD PRACTITIONER TOOLS
================================================================================

Libraries: LangChain (prompt templating + memory chaining), Anthropic Batch API
(token-efficient multi-turn reflexion), Redis (episode caching for hindsight
extraction), Weights & Biases (tracking skill quality metrics over time).

Algorithms: (1) Experience replay with prioritization (sample failed episodes
10x more often); (2) Trajectory segmentation via task boundary detection
(clustering turn-level embeddings); (3) Semantic deduplication (embedding-based
near-duplicate removal of learned skills); (4) Voting aggregation with
confidence weighting (weight each model's vote by historical accuracy on task
type); (5) Beam search over instruction edits (test 5-10 candidate rewrites
per round, keep best by validation accuracy).

Formulas: Token cost per episode ≈ (turns * tokens_per_turn) + 2x (reflexion
rewrite cost). Skill quality metric Q(s) = (pass@1_with_s - pass@1_without_s)
* -log(retrieval_time_cost / budget). Hindsight success rate = count(tau: tau
terminates & achieves goal) / total_episodes.

================================================================================
HERMES APPLICATIONS
================================================================================

COMPONENT 1: self-improve-agent / Reflexion Loop.

(a) Mathematical structure: Episodic hindsight is a form of experience replay
with trajectory segmentation. Each episode tau = (s_0, a_0, r_0, ..., s_T) is
post-hoc labeled with outcome O (success/failure/partial). Reflexion extracts
a rule R_tau = (trigger condition C, action correction A). The memory stores
{(tau, R_tau)} and retrieves top-k similar episodes by state embedding
similarity on subsequent failures.

(b) Current Hermes approach: After task failure, agent reruns with explicit
human-written or ad-hoc "lesson learned" appended to context. No structured
extraction. Memory is unranked bag of conversations, retrieved only by keyword.

(c) Principled approach: Implement structured hindsight abstraction.
(1) Segment each trajectory tau into subtasks via turn clustering (embed each
turn's state/action, cluster by cosine distance threshold 0.3).
(2) Label each segment with outcome_i in {SOLVED, BLOCKED, DEGRADED}.
(3) For each BLOCKED segment, extract rule: R = "If context_k in (feature_1,
feature_2, ...) then use skill_m instead of skill_n" via logistic regression
over feature importance.
(4) Store compact rules (< 200 tokens) with confidence score = (# supporting
episodes * success_rate_delta).
(5) On next similar failure, retrieve top-3 rules by context similarity and
prepend as "Try this approach:" to the reflexion prompt.
Convergence target: pass@1 improvement ≥ 0.12 by episode 50.

(d) Value: HIGH. Implementation cost: 1-2 weeks (segmentation + rule extraction
+ retrieval). Risk: rule overfitting to rare failure modes (low generalization).
Mitigation: cross-validate rules on held-out task variants. Math transfers well
because hindsight abstraction is task-agnostic.

COMPONENT 2: skillopt / Skill Quality Scoring.

(a) Mathematical structure: Skill quality is a composite metric Q(s_k) that
balances accuracy gain against cognitive load and retrieval cost. Formally,
Q(s_k) = alpha * (accuracy_delta_k) - beta * (size_k / 1000) - gamma *
(retrieval_latency_k), where alpha, beta, gamma are tuned empirically.
Skill depreciation: Q decays over time if task distribution E shifts.

(b) Current Hermes approach: skillopt assigns a static quality score (1-10)
based on pass rate on training tasks only. No temporal decay. No latency
penalty. Skills accumulate; old irrelevant skills clog the retrieval index.

(c) Principled approach: Implement online skill quality tracking.
(1) For each skill s_k, maintain a sliding window of last 100 uses: W_k =
[(task_i, outcome_i, latency_i), ...].
(2) Compute accuracy_delta_k = P(success | s_k used) - P(success | s_k not
used), estimated via inverse probability weighting over tasks in W_k.

FAISS). Penalize if > 50ms.

(latency_k / 100), normalized to [0, 1].
