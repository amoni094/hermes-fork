PRIMER: Random Graphs and Network Theory

========================================
1. FIELD OVERVIEW
========================================

Random graph theory studies graphs whose edges are drawn from probability distributions rather than deterministic rules. Core objects: Erdős–Rényi (ER) model (uniform random edges at rate p), configuration model (degree sequence specified, edges random), scale-free networks (preferential attachment). The field explains phase transitions (sudden emergence of giant connected components), percolation (how networks fragment under edge/node removal), and power-law degree distributions observed in real systems. Why it matters: small changes in edge density or attachment rules produce discontinuous structural changes (giant components appear at p=1/n); understanding these thresholds predicts network robustness, cascade failure modes, and information diffusion. This is foundational mathematics—not empirical heuristics—for reasoning about connectivity in systems too large to simulate exhaustively.

========================================
2. KEY RESULTS
========================================

GIANT COMPONENT THRESHOLD (Erdős–Rényi). For a random graph on n vertices with edge probability p: if p < 1/n, the largest connected component has size O(log n); if p > 1/n, a unique component of size Theta(n) emerges. Precisely, the threshold is p_c = 1/n. Proof uses branching process analysis: expected degree z = pn; if z < 1, component sizes are logarithmic; if z > 1, exponential growth occurs.

WATTS–STROGATZ SMALL WORLD. Begin with a ring lattice (degree k, high clustering) then rewire each edge with probability beta. For small beta > 0, clustering coefficient C remains high (C~k/4 for k>>1) while average shortest path L drops to L~log(n). This creates "small world"—high clustering + short paths. The transition is continuous but rapid: L drops 90% for beta ~ 0.01.

PREFERENTIAL ATTACHMENT POWER LAW. Barabási–Albert model: start with m nodes, add nodes sequentially, each node connects to m existing nodes with probability proportional to their degree. Result: degree distribution P(k) ~ k^(-3) (scale-free). More generally, if new degree d_i is proportional to current degree raised to power alpha, then P(k) ~ k^(-(alpha+2)). This explains many real networks (social, citation, web graphs).

PERCOLATION CRITICAL EXPONENTS. In random graph percolation, if p is bond occupation probability, giant component size C(p) ~ (p - p_c)^beta for p slightly above critical threshold p_c. For ER graphs, p_c = 1/n and beta = 1. Cluster size distribution follows power law with exponent tau = 5/2 at criticality. These exponents are universal across broad graph classes.

========================================
3. STANDARD PRACTITIONER TOOLS
========================================

NetworkX (Python): compute_giant_component(G), degree_centrality, clustering_coefficient, average_shortest_path_length. Graph-tool (C++, faster): degree distribution fitting, community detection. igraph (R/Python): preferential attachment model generation. Standard algorithms: BFS/DFS for component size (O(n+m)), Tarjan for strongly connected components, configuration model sampling (Molloy–Reed algorithm). Practical formulas: expected degree z = 2m/n (average); for robustness, compute size of largest component after random node removal. Fitting power law: log-log regression or maximum likelihood on tail (k >= k_min).

4. HERMES APPLICATIONS

APPLICATION 1: KNOWLEDGE GRAPH ROBUSTNESS ANALYSIS

Mathematical Structure. Hermes' skill library and entity relationships form a knowledge graph G = (V, E) where V = skills/entities, E = prerequisite/dependency edges. This graph experiences continuous perturbations: skill updates (node rewiring), memory decay (edge deletion), new skills (node/edge insertion). The question: does G remain in a single giant connected component under random failures?

Current Approach. Hermes performs no explicit robustness calculation. Skills are added heuristically; if a dependency is missing, an error occurs at runtime. There is no precomputed threshold for "how many skill deletions before the graph fragments."

Principled Approach (Random Graphs + Percolation). Treat skill dependency graph as a percolation system. Compute the critical occupation threshold p_c such that if more than (1 - p_c) fraction of edges are removed, the graph fragments. Use Molloy–Reed formula: a giant component exists if sum over all nodes v of degree(v) * (degree(v) - 2) > 0. Compute this metric after each skill update. If metric approaches 0, alert that graph is near fragmentation. Additionally, run configuration model bootstrap: sample 1000 rewirings of the current skill graph, compute giant component size distribution. If 95th percentile of component sizes drops below n*0.8, trigger proactive skill reinforcement (backfill missing prerequisites).

Value Assessment. Medium-high. Implementation cost: ~200 lines of Python using NetworkX. Risk: skill graphs may not behave like random graphs if dependencies cluster strongly (e.g., language model skills cluster separately from tool-use skills). Mitigation: test on synthetic skill graphs first, measure whether Molloy–Reed predictions match empirical fragmentation when skills fail. Real payoff: prevents silent cascade failures where loss of one skill topples 10 dependent skills.

APPLICATION 2: SKILL LIBRARY GROWTH AS PREFERENTIAL ATTACHMENT

Mathematical Structure. New skills are added to Hermes' library over time. Observed behavior: popular skills (those solving many task types) get more refinements and extensions. This matches preferential attachment: a new skill is more likely to connect to (depend on) existing highly-connected skills. Degree distribution should converge to power law P(k) ~ k^(-alpha).

Current Approach. Skills are added ad hoc based on task failures. No analysis of which skills to invest optimization effort in. skillopt scorer is applied uniformly.

Principled Approach (Preferential Attachment + Pareto). Compute degree (number of active dependencies) for each skill. Fit power law to empirical degree distribution using maximum-likelihood estimation. Identify the power law exponent alpha. Target optimization (skillopt runs, token budget allocation) proportionally to k^(alpha+1) / sum(k^(alpha+1)). This concentrates effort on the small number of "hub" skills that have outsized impact. Additionally, use the fitted alpha to project future library growth: if alpha is too high (>3), the library becomes fragile—a few super-skills dominate, so failures are catastrophic; if alpha < 2.5, growth is more distributed. Recommend skill architecture changes based on this projection.

Value Assessment. High. Implementation cost: ~100 lines for power law fitting + budget reallocation. Risk: skill usage may not follow pure preferential attachment if task distribution is non-uniform or if new skills are added strategically rather than reactively. Mitigation: log actual skill usage over 2 weeks, compute empirical degree distribution, compare to ER null model and power law fit using Kolmogorov–Smirnov test. Real payoff: direct cost reduction—concentrate optimization on 15-20 hub skills rather than spreading effort across all skills.

APPLICATION 3: RESEARCH CITATION NETWORK STRUCTURE

Mathematical Structure. Hermes' research sweep cron job collects papers and citations. The citation graph is a DAG where nodes are papers, directed edges point from citing paper to cited paper. Citation networks are known to be heavy-tailed (power law out-degree) and exhibit small-world properties. The structure predicts which papers are "foundational" (high in-degree) and which are recent/novel (low in-degree, high out-degree).

Current Approach. Hermes collects papers via keyword search, stores them, but does not analyze citation graph structure. When delegating a research task, it does not bias sampling toward foundational vs. novel papers—all are equally likely to be retrieved.

Principled Approach (Small World + Preferential Attachment). Build the citation DAG incrementally as papers are collected. Compute: (a) in-degree distribution (how many papers cite each paper); (b) clustering coefficient for the undirected version; (c) average shortest path length. Compare to Watts–Strogatz benchmark. If clustering >> small-world expectation, the graph has strong communities (subdisciplines). When retrieving papers for a task, use a two-phase strategy: (1) seed with high in-degree papers (foundational knowledge); (2) sample outgoing edges (recent developments). Concretely: retrieve top 5 papers by in-degree, then follow their outgoing citations with probability proportional to out-degree of the cited paper. This gives a breadth-first, historically grounded search.
