PRIMER: Game Theory / Mechanism Design

Game theory studies outcomes when several agents choose strategies and payoffs depend on everyone. Mechanism design inverts the problem: you choose the rules so the equilibrium is the outcome you want. For Hermes, the modeling caveat comes first. Classical results assume expected-utility maximizers with private types and, for VCG, transferable utility. Subagents are prompted workers. Their implicit payoffs are finish the task, sound confident, match the parent, avoid extra work — plus correlated errors from shared models. If independence and private values fail, auction theory does not apply; cheap talk and inspection games do.

Core concepts. A Nash equilibrium is a profile where no one gains by unilateral deviation. A dominant strategy is best no matter what others do — stronger, rarer, and the target if you can get it. Pareto optimality: no change helps someone without hurting someone else; Nash need not be Pareto (Prisoner's Dilemma). Zero-sum: one player's gain is the other's loss; mixed-strategy value is well-defined. Cooperative games allow binding agreements; most multi-agent LLM setups are non-cooperative cheap talk, not joint surplus with side payments. Mechanism design treats the designer as choosing the game. Revelation principle: anything implementable in some game is implementable by a direct mechanism where truthful type-reporting is equilibrium — so you can restrict attention to "ask them and make truth a best reply." VCG implements efficient allocation by charging each agent their externality; truth-telling is dominant, but budget balance and individual rationality conflict. Auctions are allocation plus payment; second-price is one-item VCG. Social choice aggregates rankings or votes. Correlated equilibrium (Aumann): a mediator recommends actions from a joint distribution; obedience is a best reply — cheaper than Nash, and a coordinator already is a mediator. Extensive form: sequential moves, information sets, subgame-perfect equilibrium (no non-credible threats). Stackelberg: leader commits first; follower best-responds. If the leader can be talked off the policy, it is not Stackelberg.

Key results. Minimax: two-player zero-sum finite games have a value in mixed strategies. Nash existence: every finite game has a mixed NE; existence is not uniqueness or a reason to compute one. Arrow: for ≥3 alternatives, no ranked social welfare function is simultaneously Pareto, independent of irrelevant alternatives, and non-dictatorial. Gibbard–Satterthwaite: any non-dictatorial ranked rule with ≥3 outcomes is manipulable. VCG is dominant-strategy incentive-compatible and efficient when utilities are quasi-linear.

Multi-agent delegation. (a) Incomplete-information reporting game: N workers send (claim, confidence, evidence) to a coordinator. (b) Current: isolate context, treat child output as untrusted, verify independently, majority/confidence reduce, provenance-tag. Property: confidence is cheap talk. For two agents, highest confidence wins — inflating confidence is a best reply whenever anyone is rewarded for being picked. Same-model children co-fail on ~90% of missions where either fails; the independence that makes majority informative is false. Shared memory is a correlating device (echo chamber or covert channel). (c) A mechanism would settle reports with a proper scoring rule (Brier/log) against later verification, treat evidence_refs as costly signals, and use a Clarke pivot only when choosing one exclusive plan. Blind ballots already approximate a direct mechanism. (d) Do not implement VCG. Do: keep claims binary, require evidence, never tie-break on uncalibrated confidence, no shared writes, different model families. The operative idea is cheap talk vs costly signal, not Nash computation.

Adversarial review. (a) Inspection / sender-receiver, not pure zero-sum. Proposer wants accept; reviewer wants to look thorough and not be wrong later. Payoffs are delayed and asymmetric. (b) Cross-family reviewer (gpt-5.6-sol), verbalized sampling, dual prompts, description-vs-body checks. Same-family review is a correlated strategy (sycophancy as collusive NE). Cross-family breaks that — the actual GT win. Residual mixed inspection equilibrium: neither fully hides nor fully searches. Issue-count is unincentivized; rubber-stamping and nitpicking are both equilibria depending on implicit costs. Simulator collapse if the reviewer is a frozen prompt. (c) Commit to a checklist before seeing the artifact (Stackelberg). Score the reviewer against post-merge defects. Random-audit expensive review. Do not let the proposer choose the reviewer; rotate framing. (d) Cross-family plus checklist commitment is worth it. Payment mechanisms are not; there is no transferable utility.

Consensus reduction. (a) Social choice over reports, often with hidden profiles (private unshared evidence). (b) Majority if ≥3, confidence if 2, arbiter if weak or contradictory. Summed confidence is Borda-like and IIA-violating. The arbiter is a dictator on the residual set. (c) Arrow's practical content: you cannot keep Pareto + IIA + non-dictatorship for ≥3 ranked options. Hermes already spends the dictatorship budget correctly — escalate contested cases. Keep the object binary, where majority is strategy-proof (May). For ≥3 exclusive root causes, do not vote on clones; partition, binary-reduce, or arbitrate. Frame the coordinator as a correlating mediator, not a preference aggregator. (d) Arrow is over-cited for LLM ensembles. Empirical failures — first-mover, echo chamber, hidden profile, epistemic inertia, homogeneous co-failure — are statistical dependence, not preference aggregation. Fix dependence.

Tool approval gates. (a) Stackelberg: gate commits; agent best-responds. If the gate is in-model, commitment is not credible — the SPE of the cheap-talk game is "agent proceeds." (b) Mix of prompt rules (soft) and hooks / tool-auth-gate / ATP / prefix-risk (hard). An out-of-model authorization broker is the commitment device. Self-reported confidence as a stop condition is cheap talk and miscalibrated at action time. (c) Policy outside the model; agent proposes, broker countersigns; random human audit on HAZARD; never let the agent write the risk score that unblocks it. Screening, not VCG — safety is not quasi-linear money. (d) This is where mechanism design changes architecture. In-prompt safety is not a mechanism.

Model routing as auction. (a) Assignment of tasks to models with cost and quality. An auction needs bidders with private values and payments. (b) Posted skill rules by task type; one `delegation.model` for all children; no runtime router. No strategic bidder exists. (c) Incentive-compatible routing only matters if models self-nominate fitness. Then score against realized quality; do not run Vickrey — models do not pocket payments. (d) Do not build an auction. Task-type rules beat commercial routers; two well-chosen models beat a wide pool. The auction metaphor is almost entirely false.

When GT changes Hermes: move authorization out of the model; treat confidence as cheap talk; break correlation (family diversity, blind ballots, evidence isolation); spend Arrow's dictatorship on an arbiter and keep votes binary. When it does not: VCG, Nash solvers, model-as-bidder auctions, majority-as-preference-aggregation.
