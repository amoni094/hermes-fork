# Section 5: Ergodic and Mixed Sources

## Core Idea
Among discrete Markoff processes, the ergodic ones are the sources of primary interest: every sequence (except a probability-zero set) has the same statistical properties. Shannon gives graph criteria for ergodicity, describes periodic and mixed (non-ergodic) sources, and notes that sequence averages may then be identified with ensemble averages.

## Key Concepts
- **Ergodic source**: “every sequence produced by the process is the same in statistical properties.” Letter frequencies, digram frequencies, etc., obtained from a particular sequence approach definite limits independent of the sequence as length → ∞, except on a set of probability zero. “Roughly the ergodic property means statistical homogeneity.”
- **Mixed source**: if the graph splits into isolated subgraphs (each internally ergodic), L = p1 L1 + p2 L2 + … A sequence is generated by first choosing a component Li with probability pi, then following that component forever. Physically: several homogeneous sources; we do not know a priori which is used.
- **Stationarity**: if Pi is the probability of state i and p_i(j) the transition probability, equilibrium requires Pj = ∑_i Pi p_i(j). In the ergodic case, from any start, Pj(N) → equilibrium as N → ∞.

## Key Results
**Graph criteria (restatements of Fréchet).** If both hold, the process is ergodic:
1. The graph is not two isolated parts A and B with no directed path A→B and none B→A.
2. Let a circuit be a closed directed trail; its length is the number of lines. The gcd of all circuit lengths is 1.

If (1) holds but gcd = d > 1, sequences are periodic: they fall into d classes statistically the same apart from a shift of origin. Example d = 2: letters a,b,c; a followed by b or c (probs 1/3, 2/3); b or c always followed by a. Typical sequence: abacacacabacababacac. “Not of much importance for our work.”

If (1) is violated, the graph separates into subgraphs; assuming each satisfies (2), the source is mixed.

**Working assumption.** “Except when the contrary is stated we shall assume a source to be ergodic.” This “enables one to identify averages along a sequence with averages over the ensemble of possible sequences (the probability of a discrepancy being zero).”

Appendix 3 later gives the mixed-source analogue of Theorem 4: lim log n(q)/N = φ(q), a decreasing step function equal to Hs on intervals determined by the component probabilities.

## Key Equations
- Pj = ∑_i Pi p_i(j)   (stationary distribution)
- L = p1 L1 + p2 L2 + …   (mixture)

## Significance
AEP / typical-set theorems (Theorems 3–6) require ergodicity so that −(1/N) log p(sequence) → H almost surely. Mixed sources have several typical rates. Shannon’s identification of time averages with ensemble averages is the communication-theory use of the ergodic theorem (later cited explicitly in Sec 18 via Birkhoff, von Neumann, Wiener).
