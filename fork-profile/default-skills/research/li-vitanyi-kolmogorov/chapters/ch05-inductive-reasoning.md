# Chapter 5: Inductive Reasoning

## Core Idea

Inductive reasoning is reassignment of credibility to hypotheses from data; inductive inference is the special case that accepts or rejects. Solomonoff’s theory uses the universal prior M to predict the next bit with error that sums to a finite bound depending only on the unknown computable source. The MDL principle is the practical two-part-code approximation: minimize description of the theory plus description of the data given the theory. Kolmogorov’s structure function gives a nonprobabilistic foundation for model selection on an individual sample.

## Key Concepts

- Epicurus’s principle of multiple explanations: keep every theory consistent with the observations.
- Occam’s razor: among theories consistent with the data, prefer the simplest.
- Bayes + universal prior: Epicurus (keep all) × Occam (weight by simplicity 2^{−K(μ)}) × Bayes (update). This is Solomonoff.
- Solomonoff predictor: given observed string x, predict next bit b with probability M(xb)/M(x), where M is the universal continuous semimeasure (mixture of all lower-semicomputable semimeasures on sequences).
- PAC-learning (simple): probably approximately correct identification of a concept from a class C under a distribution; Li–Vitányi connect Kolmogorov complexity to Occam algorithms and simple distributions (those dominated by m).
- MDL principle (Rissanen / Wallace, inspired by Solomonoff): given data D and an effective enumeration of alternative theories, choose the theory minimizing L(theory) + L(data | theory). Ideal MDL uses K(H) + K(D|H).
- Two-part code: first part names a model (compressor, distribution, automaton, …); second part is the data encoded with that model (ideal: −log P(D|H) ≈ K(D|H) by the coding theorem).
- Kolmogorov structure function h_x(i): the log-size of the smallest finite set S containing x with K(S) ≤ i. The minimal i where h_x(i) + i ≈ K(x) is the “sufficient statistic” complexity; below that, models underfit; above, they overfit.
- Randomness deficiency of x in S: δ(x|S) = log |S| − K(x|S). Typicality: deficiency O(1) means x is a typical element of S.
- Nonprobabilistic statistics: model selection without assuming x was sampled from a distribution; performance is judged on the individual sample.

## Frameworks and Methods

- Solomonoff induction: M = sum_μ 2^{−K(μ)} μ. After seeing x, posterior concentrates on μ that both are simple and gave x high probability. Prediction error vs the true computable μ is bounded by K(μ) in the sum of squared errors.
- Occam algorithms for PAC: if you output a short consistent hypothesis, PAC guarantees follow under m-dominated (“simple”) distributions even when worst-case PAC fails.
- Ideal MDL as Bayes with prior m: minimizing K(H) + K(D|H) is (up to O(1)) MAP with prior m(H) and likelihood 2^{−K(D|H)}. Admissible iff D is random w.r.t. Pr(·|H).
- Structure function / Kolmogorov sufficient statistic: plot h_x(i) vs i. The “elbow” (minimum of i + h_x(i)) is the shortest description of a set in which x is typical. That set is the algorithmic sufficient statistic.
- Positive vs negative randomness (Fig. 5.9): data that are typical for a simple model vs data whose only model is the singleton {x} (incompressible noise).

## Key Results and Theorems

- Solomonoff convergence: if data are generated by a computable measure μ, then sum_n (M(b_{n+1}|x_{1:n}) − μ(b_{n+1}|x_{1:n}))^2 ≤ O(K(μ)) < ∞, so prediction errors are finitely often large. On-sequence predictive distribution converges to μ almost surely.
- MDL selection rule: H_MDL = argmin_H [ K(H) + K(D|H) ]. With the coding theorem, K(D|H) ≈ −log Pr(D|H).
- Thm 5.4.1 (ideal MDL vs Bayes): under prior m, MDL selects an H for which D is Pr(·|H)-random, with probability → 1 as n → ∞.
- Occam / PAC connection: short hypotheses that fit the sample generalize on simple distributions; concept classes that are not PAC-learnable under all measures can still be learnable under m (Example 5.3.2, Exercise 5.3.9).
- Structure function properties: i ↦ h_x(i) is nonincreasing; i + h_x(i) ≥ K(x) − O(1); there exists i0 ≤ K(x) with i0 + h_x(i0) = K(x) + O(1) (the sufficient statistic). Shapes of h_x classify “stochastic,” “nonstochastic,” and intermediate objects.
- Sufficient statistic: a set S ∋ x with K(S) + log |S| ≈ K(x) and K(x|S) ≈ log |S| (x typical in S). Then S captures all meaningful regularities; the remainder is noise.
- DFA identification: smallest automaton consistent with a sample is the MDL choice in that model class; exact and approximate identification are NP-hard, but the principle still names the target.

## Algorithms and Techniques

1. Solomonoff (noncomputable): approximate M from below by dovetailing all programs; predict with the current ratio M̂(x1)/M̂(x). The approximation is one-sided.
2. Practical MDL: replace K by a two-part code with a chosen description language (NML, BIC as asymptotic MDL, two-part Shannon codes). Never claim the result is the ideal K-MDL.
3. Structure function computation (noncomputable): for each i, search for a set S with K(S) ≤ i containing x of minimal log-size. Approximations: Kolmogorov’s ML estimator, and practical clustering / lossy compression.
4. Hypothesis list: fix an effective enumeration H1, H2, … (e.g. all DFAs, all polynomials, all Markov chains of each order). MDL is well-defined only relative to that list.
5. Typicality check: after selecting H, test whether K(D|H) ≈ −log Pr(D|H); if D is too compressible given H, H is underfit; if too incompressible, H is overfit or wrong.

## Anti-patterns

- Collapsing Epicurus and Occam: keeping all theories without weighting by simplicity is Epicurus alone; it does not predict. Weighting without keeping all (hard selection of one H) is MDL, which can be wrong on small samples.
- Using the principle of indifference as a prior: Bertrand’s paradox (water/wine ratio) shows that “uniform in this parameterization” is language-dependent. The universal prior m is invariant up to a multiplicative constant.
- Treating MDL as “always pick the shortest program for the data”: that is one-part code K(D), which overfits (the model can be the data itself). Two-part is essential: K(H) + K(D|H).
- Applying PAC worst-case bounds and concluding unlearnability: many classes are learnable under simple (m-dominated) distributions.
- Ignoring that Solomonoff, m, and K are incomputable: computable approximations (MDL, two-part Shannon, cross-validation) are not guaranteed to inherit the sum-error bound.
- Reading the structure function as a probability: h_x(i) is combinatorial (log-cardinality), not a likelihood, until you interpret 2^{−h_x(i)} as a uniform distribution on S.

## Key Takeaways

1. Solomonoff = Epicurus + Occam + Bayes with the universal prior; it is the theoretically optimal predictor for computable sources.
2. MDL is the computable-practice shadow of that theory: two-part codes, model class explicit, ideal form K(H)+K(D|H).
3. A good model is a short set in which the data are typical, not merely a set that contains the data.
4. The structure function is Kolmogorov’s last word on statistics: model selection without a sampling assumption.
5. Invariance of m (Ch 4) is what makes Occam’s razor language-independent up to O(1).
