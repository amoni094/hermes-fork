# Glossary — Li and Vitányi, Kolmogorov Complexity (4th ed., 2019)

Terms -- definition (Ch N). Book notation: **C** = plain complexity, **K** = prefix complexity.

- Admissible information distance -- total nonnegative D with D(x,y)=0 iff x=y, upper semicomputable, and sum_{y≠x} 2^{−D(x,y)} ≤ 1. (Ch 8)
- Algorithmic entropy -- K of an individual microstate; vs thermodynamic log |Γ|. (Ch 8)
- Algorithmic information I(x : y) -- K(y) − K(y|x). Exact symmetry needs y | x*. (Ch 3)
- Algorithmic mutual information I(x ; y) -- K(x) + K(y) − K(x, y). Symmetric to O(1). (Ch 3)
- Algorithmic probability -- 2^{−K(x)}; also Q_U(x) = sum_{U(p)=x} 2^{−l(p)}. Equal to m(x) up to Θ(1) by the coding theorem. (Ch 4)
- A priori probability Q_U -- probability that prefix U outputs x on fair-coin input. (Ch 4)
- Average-case via incompressibility -- runtime on an incompressible input equals the uniform average up to tails. (Ch 6)
- Bennett uncomputing -- reverse a reversible history after copying output, to erase garbage. (Ch 8)
- Berry paradox (Richard–Berry) -- “least number not definable in fewer than twenty words.” Blocked by requiring effective descriptions; reappears as incompleteness. (Ch 1)
- C(x) -- plain Kolmogorov complexity: min { l(p) : U(p)=x } on an ordinary universal TM. (Ch 2)
- C(x|y) -- conditional plain complexity, y on the auxiliary tape. (Ch 2)
- C(x, y) -- C(⟨x,y⟩), joint plain complexity. Not subadditive to O(1). (Ch 2)
- C^t(x) -- time-bounded plain complexity. (Ch 7)
- Chaitin’s Ω -- sum_{U(p)↓} 2^{−l(p)}; Martin-Löf random real encoding the halting problem. (Ch 3)
- Coding theorem -- log 1/m(x) = log 1/Q_U(x) = K(x) up to O(1). (Ch 4, Thm 4.3.3)
- Conditional semimeasure m(x|y) -- mixture of lower-semicomputable conditionals; −log m(x|y) = K(x|y)+O(1). (Ch 4)
- Crossing sequence -- states seen at a tape cell; short crossings compress the input. (Ch 6)
- Discrete semimeasure -- P : N → [0,1] with sum P ≤ 1. (Ch 4)
- Epicurus’s principle -- keep all theories consistent with the data. (Ch 5)
- E1(x, y) -- max{K(x|y), K(y|x)}, universal admissible information distance. (Ch 8)
- Gödel incompleteness via incompressibility -- “x is random” unprovable in any short sound F for almost all random x. (Ch 1)
- Halting problem -- not recursive; implies C, K, m are not computable. Ω’s bits solve it. (Ch 1, 3)
- Incompressibility method -- prove P for a C-random object by showing ¬P would compress it. (Ch 6)
- Incompressible / C-random string -- C(x) ≥ l(x) (or ≥ l(x)−c). (Ch 2)
- Instance complexity ic^t(x : L) -- shortest fast program that correctly decides this instance of L. (Ch 7)
- Invariance theorem -- additively optimal universal machine exists for partial computable (C) and prefix (K) functions; |C_U − C_V| = O(1). (Ch 2 Thm 2.1.1, Ch 3 Thm 3.1.1)
- K(x) -- prefix Kolmogorov complexity: shortest self-delimiting program. (Ch 3)
- K(x|y) -- conditional prefix complexity. Domain is prefix-free for each fixed y, not jointly. (Ch 3)
- Kolmogorov random graph -- graph whose adjacency-triangle is incompressible. (Ch 6)
- Kolmogorov sufficient statistic -- set S ∋ x with K(S)+log |S| ≈ K(x) and x typical in S. (Ch 5)
- Kraft inequality -- prefix-code lengths exist iff sum 2^{−ℓ_i} ≤ 1. (Ch 1)
- Kraft–Chaitin -- r.e. sequence of lengths with Kraft sum ≤ 1 yields a prefix machine. (Ch 3)
- Kt(x) -- Levin complexity min { ℓ(p)+log t : U(p)=x in t steps }. (Ch 7)
- Landauer’s principle -- erasing one bit dissipates ≥ kT ln 2. (Ch 8)
- Language compression -- time/space-bounded C of strings in a language. (Ch 7)
- Levin search / universal search -- dovetail programs with time share 2^{−ℓ(p)}; optimal inversion up to 2^{K(A)}. (Ch 7)
- Logical depth -- time at which most of Q_U-mass for x appears; organized complexity. (Ch 7)
- Lower semicomputable -- enumerable from below by a monotone computable approximation. (Ch 4)
- m(x) -- reference universal lower-semicomputable discrete semimeasure. (Ch 4)
- M(x) -- universal continuous semimeasure (Solomonoff mixture on {0,1}^∞). (Ch 4, 5)
- Martin-Löf randomness -- passes all effective sequential tests; equivalent K-criteria in Table 3.1. (Ch 2–3)
- MDL -- min L(theory)+L(data|theory); ideal form argmin_H K(H)+K(D|H). (Ch 5)
- Muchnik’s theorem -- shortest conversion programs p : y→x and q : x→y can share almost all information. (Ch 8)
- NCD -- normalized compression distance, compressor approximation to NID. (Ch 8)
- NID e(x,y) -- max{K(x|y),K(y|x)} / max{K(x),K(y)}, universal similarity metric. (Ch 8)
- Occam’s razor -- prefer simpler hypotheses; formalized as prior 2^{−K(H)}. (Ch 5)
- Pairing ⟨x,y⟩ -- computable bijection N×N → N. (Ch 1–2)
- PAC-learning -- probably approximately correct identification; Occam algorithms + simple (m-dominated) distributions. (Ch 5)
- Plain vs prefix -- C allows non-prefix programs; K requires prefix-free domain. (Ch 2–3)
- Prefix machine / self-delimiting machine -- never reads past the program; domain prefix-free. Time-bounded equivalence open. (Ch 3, 7)
- Q_U(x) -- a priori / algorithmic probability of x. (Ch 4)
- Quantum Kolmogorov complexity -- shortest program (classical or quantum) for a state |ψ⟩; several inequivalent definitions. (Ch 8)
- Randomness deficiency δ(x|S) -- log |S| − K(x|S); typicality when O(1). (Ch 5)
- Reference machine U -- fixed additively optimal universal (prefix) TM. Additive constants depend on U. (Ch 2–3)
- Reversible TM / Kr -- Kolmogorov complexity relative to reversible computation. (Ch 8)
- Self-delimiting integer code -- 1^{ℓ(n)}0 n, length 2ℓ(n)+1; better: ℓ(n)+2ℓ(ℓ(n))+1. (Ch 1)
- Semimeasure vs measure -- sum/mass ≤ 1 vs = 1; leftover = non-halting. (Ch 4)
- Shannon entropy H(P) -- ensemble uncertainty; E_P[K] ≈ H(P)+K(P). (Ch 1, 8)
- Simple distribution -- multiplicatively dominated by m. (Ch 5)
- Solomonoff induction -- predict with M(xb)/M(x); Epicurus × Occam × Bayes. (Ch 5)
- Structure function h_x(i) -- min log |S| over S ∋ x with K(S)≤i. (Ch 5)
- Subadditivity -- K(x,y) ≤ K(x)+K(y)+O(1); C needs an extra 2 log min(C(x),C(y)). (Ch 2–3)
- Symmetry of information -- K(x,y) = K(x)+K(y|x,K(x))+O(1). (Ch 3, Thm 3.8.1)
- Time-limited universal distribution m^t -- resource-bounded analogue of m. (Ch 7)
- Two-part code -- model bits + data-given-model bits; core of MDL. (Ch 5)
- Universal discrete distribution -- the common Θ-class of m, Q_U, 2^{−K}. (Ch 4)
- Universal prior -- m or M; invariant up to a multiplicative constant. (Ch 4–5)
- Universal TM -- simulates any TM; basis of invariance. (Ch 1–2)
- Upper semicomputable -- enumerable from above (C and K are). (Ch 2)
