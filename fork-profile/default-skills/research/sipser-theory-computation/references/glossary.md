# Sipser — Glossary of Terms

## A

**Accept state (F):** State of DFA/NFA whose entry ends computation by accepting the input string.

**Algorithm:** A TM that halts on every input. Synonymous with decider.

**ATM:** {⟨M,w⟩ | M is a TM that accepts w}. Paradigmatic undecidable language.

**Alphabet (Σ):** Finite nonempty set of symbols.

## B

**Blank symbol (□):** Special tape symbol not in input alphabet; marks unused tape cells.

**BPP:** Bounded-error Probabilistic Polynomial time. Likely equals P.

## C

**Certificate:** Witness string c verifying w ∈ L for NP languages. |c| ≤ polynomial in |w|.

**CFG (Context-Free Grammar):** G = (V,Σ,R,S). Productions A→w. Generates CFLs.

**CFL (Context-Free Language):** Language generated by some CFG. Recognized by nondeterministic PDA.

**Church–Turing Thesis:** TMs capture all effective computation. Thesis (not theorem).

**CNF (Chomsky Normal Form):** Productions of form A→BC or A→a. Every CFG has CNF equivalent.

**Complement:** L̄ = Σ* \ L. If L decidable, L̄ decidable. If L Turing-recognizable and L̄ Turing-recognizable, then L decidable.

**Computable function:** f: Σ*→Σ* computed by TM that halts on all inputs with f(w) on tape.

**Configuration:** Snapshot of TM computation: (state, tape, head position).

**Co-NP:** Class of languages whose complements are in NP.

## D

**DCFL:** Deterministic Context-Free Language. Recognized by DPDA. Proper subset of CFL. Closed under complement.

**Decider:** TM that halts (accepts or rejects) on every input.

**Decidable:** L is decidable iff some TM decider recognizes L.

**DFA (Deterministic Finite Automaton):** M=(Q,Σ,δ,q₀,F), δ: Q×Σ→Q.

**Diagonalization:** Proof technique (Cantor). Construct object that differs from every listed item on the diagonal entry.

## E

**Enumerator:** TM with printer output. L(M) = set of strings printed. L is Turing-recognizable iff some enumerator enumerates it.

**Exponential time (EXPTIME):** ⋃_k TIME(2^(n^k)).

## H

**Halting problem:** HALT_TM = {⟨M,w⟩ | M halts on w}. Undecidable. Turing-recognizable.

## I

**Indistinguishable states:** States p,q indistinguishable in DFA iff L(M_p) = L(M_q). Used in DFA minimization.

## L

**L (logspace):** SPACE(log n).

**Language:** L ⊆ Σ*. Central object of study.

**LR(k) grammar:** Deterministic CFG; can be parsed left-to-right with k-token lookahead.

## M

**Many-one reducibility (≤_m):** A ≤_m B if computable f exists with w∈A ↔ f(w)∈B.

**Mapping reducibility:** See many-one reducibility.

## N

**NFA (Nondeterministic Finite Automaton):** δ: Q×Σε→P(Q). Equivalent to DFA.

**NL:** NSPACE(log n). Contains PATH (graph reachability). NL = coNL.

**NP:** Languages with polynomial-time verifiers, or languages decided by polynomial-time NTMs.

**NP-complete:** NP-hard ∩ NP.

**NP-hard:** ∀A∈NP: A ≤_p B.

**NTM (Nondeterministic Turing Machine):** δ: Q×Γ→P(Q×Γ×{L,R}). Accepts if any branch accepts.

## O

**Oracle:** Hypothetical device that answers membership queries for a fixed language B in O(1). Relativized computation.

## P

**P:** ⋃_k TIME(n^k). Polynomial-time decidable.

**PDA (Pushdown Automaton):** NFA + stack. Recognizes CFLs.

**PSPACE:** ⋃_k SPACE(n^k). Contains NP. Equals IP.

**PSPACE-complete:** TQBF, Generalized Geography.

**Polynomial reducibility (≤_p):** Many-one reduction computable in polynomial time.

**Pumping length (p):** Minimum length of strings in regular/CFL language that can be pumped.

## R

**Recognizer:** TM that accepts all strings in L but may loop on L̄.

**Recursion Theorem:** TM can obtain its own description.

**Regular language:** L recognized by some DFA. Closed under ∪, ∩, ¬, ∘, *.

**Rice's Theorem:** Any nontrivial property of TM languages is undecidable.

## S

**SAT:** {⟨φ⟩ | φ is a satisfiable Boolean formula}. NP-complete (Cook–Levin).

**SPACE(f(n)):** Languages decidable by O(f(n))-space TM.

**State (q):** Node in DFA/NFA/TM transition diagram.

**String:** Finite sequence of alphabet symbols.

## T

**TIME(t(n)):** Languages decidable by O(t(n))-time TM.

**TM (Turing Machine):** M=(Q,Σ,Γ,δ,q₀,q_acc,q_rej). Universal model of computation.

**TQBF:** True Quantified Boolean Formulas. PSPACE-complete.

**Transition function (δ):** Core of DFA/NFA/TM. Maps (state, symbol) → next configuration.

**Turing-recognizable:** L recognized by some TM. Closed under ∪, ∘, *. Not closed under complement.

**Turing reducibility (≤_T):** A ≤_T B if A decidable relative to oracle B.

## U

**Undecidable:** Language with no TM decider. Examples: ATM, HALT_TM, E_TM.

**Universal TM (UTM):** TM that simulates any TM M on input w given ⟨M,w⟩.

## V

**Verifier:** TM V where L = {w | ∃c: V accepts ⟨w,c⟩}. Polynomial-time verifier characterizes NP.

## W

**w (string):** Finite sequence w = w₁w₂…wₙ over Σ. |w| = length. ε = empty string.
