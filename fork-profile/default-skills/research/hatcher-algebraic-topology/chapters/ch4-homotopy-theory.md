# Chapter 4: Homotopy Theory

## Core Topics
- Higher homotopy groups πₙ (§4.1)
- Computation methods: Hurewicz, excision, fiber bundles (§4.2)
- Connections with cohomology: fibrations, Postnikov towers (§4.3)

## 4.1 Homotopy Groups

### Definition
πₙ(X, x₀) = homotopy classes of maps (Sⁿ, *) → (X, x₀) rel basepoint.
Equivalently: maps (Dⁿ, Sⁿ⁻¹, s₀) → (X, x₀, x₀).
Group operation: concatenate Sⁿ = Dⁿ⊔_{Sⁿ⁻¹} Dⁿ.

**For n≥2**: πₙ(X) is abelian (two independent directions to commute maps).

### Key Computations
| Space | π₁ | π₂ | π₃ | π₄ |
|-------|-----|-----|-----|-----|
| S¹ | ℤ | 0 | 0 | 0 |
| S² | 0 | ℤ | ℤ (Hopf!) | ℤ/2 |
| S³ | 0 | 0 | ℤ | ℤ/2 |
| T² | ℤ² | 0 | 0 | 0 |
| ℝPⁿ | ℤ/2 | ℤ | ℤ | ℤ/2 |

Note: π₃(S²)=ℤ generated by Hopf fibration η: S³→S² (fiber=S¹).

### Whitehead's Theorem
If f: X→Y is a map between CW complexes inducing isomorphisms
f∗: πₙ(X)→πₙ(Y) for all n, then f is a homotopy equivalence.

**Warning**: Does NOT hold for general spaces (Whitehead's theorem requires CW complexes).

### Cellular Approximation
Every map f: X→Y between CW complexes is homotopic to a cellular map
(one carrying Xⁿ into Yⁿ for all n). Consequence: πₙ(Sᵐ)=0 for n<m.

### CW Approximation
Every space X has a CW complex Z with a weak homotopy equivalence Z→X
(inducing isomorphisms on all πₙ). This allows use of CW methods for general spaces.

## 4.2 Computation Methods

### Homotopy Excision (Freudenthal Suspension)
For (n-1)-connected space X:
**Suspension isomorphism**: πₖ(X) ≅ πₖ₊₁(SX) for k < 2n-1.

This leads to **stable homotopy groups**: πₙₛ = lim_{k→∞} πₙ₊ₖ(Sᵏ).

### Hurewicz Theorem
If X is (n-1)-connected (πₖ(X)=0 for k<n, n≥2):
- Hₖ(X)=0 for 0<k<n
- The **Hurewicz map** h: πₙ(X)→Hₙ(X), [f]↦f∗([Sⁿ]), is an isomorphism
- If n=1: h: π₁(X)→H₁(X) is the abelianization map

**Application**: For simply connected spaces, the first nonzero homotopy group
equals the first nonzero homology group.

### Fiber Bundles
A **fiber bundle** p: E→B with fiber F is a map where each b∈B has a
neighborhood U with p⁻¹(U) ≅ U×F (locally trivial).

Examples:
- Hopf fibration: S¹→S³→S² (also S³→S⁷→S⁴, S⁷→S¹⁵→S⁸)
- Covering spaces (discrete fiber)
- Frame bundles of manifolds

**Long exact sequence of a fibration**:
→ πₙ(F) → πₙ(E) → πₙ(B) →^∂ πₙ₋₁(F) → ... → π₀(E) → π₀(B)

## 4.3 Connections with Cohomology

### Eilenberg-MacLane Spaces K(G,n)
Unique (up to homotopy equivalence) space with πₙ=G, πₖ=0 for k≠n.
Representability: Hⁿ(X;G) ≅ [X, K(G,n)] (homotopy classes of maps).

This gives cohomology a purely homotopy-theoretic interpretation.

### Fibrations and Long Exact Sequence
A **fibration** p: E→B has the homotopy lifting property for all spaces.
- More general than fiber bundles but same long exact sequence
- Serre fibrations: lifting for CW pairs sufficient
- Every map is a fibration up to homotopy (via mapping path space construction)

**Postnikov tower**: Every simply connected CW complex X is the homotopy limit
of a tower:
X → ... → Pₙ(X) → Pₙ₋₁(X) → ... → P₁(X) = K(π₁,1)
where Pₙ(X) has πₖ = πₖ(X) for k≤n, πₖ=0 for k>n.
Each stage Pₙ→Pₙ₋₁ is a fibration with fiber K(πₙ,n).

### Obstruction Theory
For lifting a map through a fibration with fiber K(G,n), there is an
obstruction class in Hⁿ⁺¹(X;G). Lifting exists iff obstruction vanishes.

Key application: Existence of sections of fiber bundles controlled by cohomology.

## Stable Homotopy Theory

Stable homotopy groups πₙₛ = πₙ₊ₖ(Sᵏ) for k large:
- πₛ₀ = ℤ, πₛ₁ = ℤ/2, πₛ₂ = ℤ/2, πₛ₃ = ℤ/24

**Spectra**: Generalized cohomology theories correspond to spectra.
Suspension spectrum of X: Σ∞X, with πₙ = πₛₙ(X).

This stabilization idea appears in persistent homology (barcodes stable under perturbation).
