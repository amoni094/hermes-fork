# Dashboard Scope Ladder

Use this quick ladder before loading the full local-personal-dashboard playbook.

## Scope ladder
1. tiny local dashboard with a few panes and no persistence
2. pane-refresh dashboard with separate lightweight endpoints
3. personalized dashboard using existing local taste/seed/reference data
4. entity-watch / policy / recommendation dashboard with richer refresh logic

## Routing rule
- if the user only wants a small local homepage/dashboard -> this skill is appropriate
- if the task is mainly about data refresh or recommendation logic, use the relevant specialist/reference first, then come back here for the UI shell
- if the user wants a bigger app/framework/product surface, start with a written plan before implementation
