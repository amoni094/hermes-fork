# Mariam's Cleaning Business — Accumulated Context

## Structure

- Mariam: sole trader, business owner, operator
- User: admin/operations partner, AI agent tooling contributor
- Profit split: 70–75% Mariam / 25–30% user (25% if agent primarily saves user time; 30% if it replaces functions Mariam would otherwise pay for)
- User retains ownership of the Hermes AI agent setup — it travels with the user if the business ends

## Target market

- Residential / domestic cleaning, Australia
- Primary revenue channel under development: NDIS Household Tasks (Registration Group 0120)
- NDIS pathway chosen: start as unregistered provider (self-managed and plan-managed participants only) while pursuing Verification audit for full registration

## NDIS registration requirements (Household Tasks / 0120)

Unregistered (can start immediately):
- NDIS Worker Orientation Module (free, ~1–2 hrs online)
- Police check
- Public liability insurance
- Basic service agreement template
- Can only work with self-managed and plan-managed participants

Registered (full access):
- All of the above
- Verification audit (desktop-only, not in-person) — ~$900–1,500, weeks to months
- NDIS Worker Screening Check for all workers
- NDIS Practice Standards compliance
- Selecting ONLY Group 0120 keeps audit in the cheaper Verification pathway (not Certification)

NDIS pricing (Household Tasks): set by NDIA price guide; currently ~$55–60/hr (check current NDIS Price Guide for exact figure)

## Staffing notes

Preferred model: ABN contractors initially (simpler, no payroll overhead). Transition to casual employment if volume and regularity warrants it.

NDIS workers need:
1. NDIS Worker Orientation Module (free)
2. NDIS Worker Screening Check (takes days to weeks — do not roster on NDIS clients until cleared)
3. Police check

Sourcing channels ranked by speed: community/WhatsApp groups and referrals for first hires; Seek/Facebook/Gumtree for volume.
